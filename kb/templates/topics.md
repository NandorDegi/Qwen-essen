# Topics

Each note has exactly one `topic/*` tag. The layer tag tells **who** the note is for. The topic
tag tells **what** the note is about. This note is the only list of topics. Do not use a topic
that is not in this list.

## How to choose the set

- Keep the set small: approximately 10 to 20 topics.
- A topic needs several notes. Merge a topic that has only one or two notes.
- Split a topic that has more than approximately 70 notes, or that covers unrelated subjects.
- A topic must match a cluster of notes that link to each other. If the notes of one topic do not link to each other, the topic is wrong.
- An umbrella topic keeps its products as plain tags. For example, `topic/dataops` with the plain tags `product-a` and `product-b`.
- To add, merge or retire a topic, write a decision record. Then retag the notes in one batch.
